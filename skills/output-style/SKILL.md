# 出力対象に合わせて記述する

出力する内容に応じて、[共通ルール](references/output-common.md) と必要な対象のルールを読み、記述・編集・提出前の確認に適用する。

| 出力対象 | 読むルール |
|---|---|
| チャット・Workでの返答、進捗・完了報告 | [応答](references/output-response.md) |
| 仕様書、手順書、README、Issue・PR本文、スキル本文など | [ドキュメント](references/output-document.md) |
| 実装、コードコメント | [コード](references/output-code.md) |

画面やファイル形式ではなく、内容で選ぶ。チャット内で仕様書を書く場合もドキュメントとして扱い、添える返答には応答ルールを使う。複数の対象があれば該当するものだけ読む。

ユーザーの指定、対象リポジトリの規約、必要なテンプレートを尊重する。短さや言葉の好みだけで、必要な情報・挙動を削らない。読み取り専用の依頼では指摘までにとどめ、記述ルールから編集・投稿・公開の権限を推定しない。

提出前に、理解や判断に不要な説明・反復・装飾、過去案への打ち消しがないか確認する。編集で必要な条件・根拠・不確実性・挙動を失っていないか確認し、コードを変更した場合は変更に応じた動作確認を行う。
