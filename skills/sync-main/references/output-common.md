# 共通の記述ルール

- 読み手と目的に合わせて、必要な情報を選ぶ。関連情報を網羅すること自体を目的にしない。
- 事実、推測、提案、未確認事項を区別する。根拠のない事実・数値・評価・方針・手順を加えない。助言が必要な場合は、確定事項と区別して提案する。
- 編集によって、条件、例外、確信度、必要な挙動を変えない。
- 普段使う言葉で具体的に書く。抽象語や独自の呼び名で説明を省略しない。
- 「正本」「証跡」「担保」「粒度」「解像度」などは、文脈上必要な意味がある場合に使う。正式な用語や既存の名称は尊重する。
- 現在の方針や動作を直接書く。採用しなかった案を否定するだけの説明を付け足さない。
- 言葉や記号だけでAIらしさを判定しない。その箇所が理解に役立つかで判断する。
- 人間らしさを演出するために、体験、感情、口癖、誤字を追加しない。

提出前に、理解や判断に不要な説明・反復・装飾と、過去案への打ち消しを確認する。削除や言い換えによって、必要な条件・根拠・不確実性・挙動を失わない。
